Founding Pro setup

This is local Claude Code protection setup — clone Tripward, then run the commands in your project repo.

Step 1 — Clone Tripward

git clone https://github.com/gage-cmd/tripward.git tripward && cd tripward && npm install

Step 2 — In your project repo (replace /path/to/tripward)

npx tsx /path/to/tripward/src/cli.ts init --preview
npx tsx /path/to/tripward/src/cli.ts init
npx tsx /path/to/tripward/src/cli.ts doctor
npx tsx /path/to/tripward/src/cli.ts run
npx tsx /path/to/tripward/src/cli.ts protect --mode enforce
npx tsx /path/to/tripward/src/cli.ts receipt --html
npx tsx /path/to/tripward/src/cli.ts restore --preview --html
